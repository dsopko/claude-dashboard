Correction (2026-08-24). This caption previously read "Needs You sorts oldest first (the longest-blocked agent tops the list — here the 9-minute rate-limit error)", and the Needs-You rows below are still drawn in that superseded order — Error above Question above Permission, which is the reverse of the ratified rule. The ordering authority is TS §IV.2/§IV.3 (ratified in e645fd8, then 2860e14); Design §5 was reconciled in 00a9954. The rationale changed from age to throughput: a permission is usually seconds of operator time standing between an agent and an indefinite wait, so clearing it returns the most blocked capacity per second of attention; an error is often self-recoverable on retry; a question may need real thought, and thinking about it unblocks nothing else meanwhile. Use this file for visuals only — never for ordering. The single implementation lives in AttentionOrder and is consumed by both the attention engine and Group.WorstState. Found at T1.11.
